# abhaythakur-portfolio

Cinematic personal portfolio showcasing AI/ML engineering, data science, generative AI, and real-world projects.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS
- Framer Motion & Lenis Smooth Scroll
- Formspree Contact Integration

## Getting Started

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
